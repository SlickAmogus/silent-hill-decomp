Silent Hill Save Converter

Move saves between the PC port (gamedata/save/N.MCD), DuckStation and a real PlayStation memory card, and inspect or edit what is inside them. Everything runs in this page; nothing is uploaded.

To edit: load a card, click a Silent Hill block, then Edit on a save. Use the arrows to reorder saves, then Download edited card.

1 · Load cards

Drop memory cards or the PC port's save folder here.

DuckStation .mcd, real-card dumps (.mcr, .mc, DexDrive .gme, PSP .vmp) and PC port 0.MCD…11.MCD. A PC card is recognised by its name, so keep those names as the game wrote them.

2 · Convert

PSX cards → PC saves

Takes the Silent Hill files from each PSX card and builds PC cards. The first card becomes 0.MCD (Memory Card 1), the second 8.MCD (Memory Card 2). Other games' saves are left out.

PC saves → PSX cards

Builds one card per PC card, named the way DuckStation names per-game cards. Titles and icons are fixed so the PS1 memory card screen shows them properly. Pick the disc you will play: each region's game only sees saves named for it.

Add saves into an existing card

Copies the Silent Hill saves from every other loaded card into a copy of the card you pick. Its own saves, from any game, stay. Clashing file numbers get the next free number. Saves added to a PSX card take the region of the Silent Hill saves already on it, or the disc picked under "PC saves → PSX cards" if it has none.

3 · Result

How the three formats relate

All three are the same thing: a raw 128 KB PlayStation memory card image, 16 blocks of 8 KB. Block 0 is the directory, blocks 1 to 15 hold saves. DuckStation .mcd and a real-card .mcr are byte-for-byte the same format.

The PC port stores one image per memory card slot. Silent Hill supports the multitap, but the PC port connects only Memory Card 1 and 2 (0.MCD and 8.MCD). Older builds also created the multitap files below; empty ones can be deleted.

Each Silent Hill file (BASLUS-00707SILENT00 … SILENT14, shown as FILE01 to FILE15) is one block and holds 11 save slots plus your options. So one card holds up to 15 files and 165 saves.

The save data inside a file is identical on PC and PS1. The only differences are in the wrapper: PC-written directories have no checksums, and older PC builds wrote a garbled title and no icon. This tool writes fully standard cards, which the PC port, DuckStation and real hardware all read.
